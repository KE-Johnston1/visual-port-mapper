# Security Policy

## Scope

This repository is an educational cybersecurity portfolio project. It is designed to process synthetic or explicitly authorised Nmap XML evidence and does not perform live scanning, exploitation, packet capture or automated incident response.

## Reporting a security issue

If you identify a security vulnerability in the code, please use GitHub's private vulnerability reporting or security advisory mechanism where available rather than opening a public issue containing sensitive details.

When reporting an issue, include enough information to reproduce the problem safely, such as the affected file/function, input conditions, observed behaviour and potential impact. Do not include real credentials, private logs, customer data or other sensitive information.

## Responsible disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing a security issue. Do not test this project against systems you do not own or have explicit permission to assess.

## Supported code

The current `main` branch is the primary supported version of the project. Development branches may contain incomplete changes.
